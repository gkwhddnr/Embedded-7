# 라즈베리파이 안전모 탐지 실험 가이드

## 목표와 준비물

라즈베리파이 5와 Camera Module 3에서 `helmet_camera.py`와 학습된 `best.pt`를 실행한다. 실행 시 안전모 탐지 결과를 라즈베리파이 화면에 표시한다. 현재 코드는 신뢰도 기준 `conf=0.5`를 사용하며 휴대전화 알림, NFC, LED 및 부저 기능은 포함하지 않는다.

- Raspberry Pi OS가 설치된 라즈베리파이 5와 Camera Module 3
- 카메라와 Pi 5를 연결하는 15핀-22핀 카메라 케이블
- 라즈베리파이 데스크톱 화면 또는 모니터, 키보드
- 인터넷 연결 및 패키지를 설치할 충분한 저장 공간
- 같은 폴더에 있는 `helmet_camera.py`, `best.pt`

**이 문서의 모든 명령은 라즈베리파이 터미널에서 실행한다.** 노트북 WSL의 가상환경은 Git에 추가하거나 라즈베리파이로 복사하지 않는다. 라즈베리파이에서 별도로 구성한다.

## 1. 라즈베리파이 가상환경 준비

라즈베리파이에서 기존 `proj` 폴더로 이동한다. 실제 저장 경로를 사용하며, 현재 위치는 다음으로 확인한다.

```bash
pwd
```

이 폴더의 `helmet_camera.py`와 `best.pt`를 이용하되 파일 확인은 가상환경 구성 후에 진행한다.

### 저장 공간 확인

이전에 설치 중 저장 공간 부족이 발생했으므로 먼저 확인한다.

```bash
df -h . /tmp
```

`Avail`이 남은 공간이다. Ultralytics 설치 시 PyTorch 등 큰 패키지가 추가될 수 있으며 설치 중 임시 공간도 필요하다. 여유 공간이 부족하면 중단 원인을 확인한 뒤 확보한다. 프로젝트 폴더와 모델을 임의로 삭제하지 않는다.

### 가상환경과 카메라에 필요한 시스템 패키지 설치

아래 명령은 가상환경 안팎 어느 쪽에서 실행하더라도 시스템 패키지를 설치한다. 비밀번호는 라즈베리파이 사용자 비밀번호이며 입력 시 화면에 보이지 않는다.

```bash
sudo apt update
```

```bash
sudo apt install -y python3-venv python3-pip python3-picamera2 python3-opencv
```

- `python3-picamera2`: Camera Module 3 접근
- `python3-opencv`: 영상 표시용 `cv2`
- `python3-venv`, `python3-pip`: 가상환경과 파이썬 패키지 설치

시스템 파이썬에서 Picamera2를 확인한다.

```bash
/usr/bin/python3 -c "from picamera2 import Picamera2; print('system Picamera2 OK')"
```

오류가 나오면 다음 설치를 반복하기 전에 오류 내용을 확인한다. Picamera2는 `pip` 대신 Raspberry Pi OS의 `apt` 패키지를 우선 사용한다.

### 라즈베리파이 전용 가상환경 생성

**라즈베리파이의 프로젝트 폴더에서** 아래 명령을 실행한다. 이름 `helmet.env`는 사용자가 변경해도 된다. 이 가상환경은 노트북 WSL의 `helmet.env`와 별개다.

먼저 같은 이름의 항목이 이미 있는지 확인한다.

```bash
ls -ld helmet.env
```

`No such file or directory`가 나오면 다음 명령으로 새로 만든다.

```bash
python3 -m venv --system-site-packages helmet.env
```

이미 `helmet.env`가 있다면 위 생성 명령을 바로 다시 실행하지 말고 기존 가상환경인지 확인해 사용한다. **기존 폴더를 삭제하거나 덮어쓰지 않는다.** `--system-site-packages`는 시스템에 설치한 Picamera2 등을 가상환경에서 사용할 수 있게 한다.

가상환경을 활성화한다.

```bash
source helmet.env/bin/activate
```

터미널 앞에 `(helmet.env)`가 표시되는지 확인하고 다음을 실행한다.

```bash
cat "$VIRTUAL_ENV/pyvenv.cfg"
```

다음 설정이 표시되어야 한다.

```text
include-system-site-packages = true
```

기존 가상환경에서 `false`가 나오면, 해당 가상환경이 맞는지 확인한 뒤 다음 순서로 수정한다.

현재 가상환경 경로를 저장한다.

```bash
helmet_env_path="$VIRTUAL_ENV"
```

설정 파일을 연다.

```bash
nano "$helmet_env_path/pyvenv.cfg"
```

`include-system-site-packages = false`를 `include-system-site-packages = true`로 바꾼 뒤 `Ctrl+O`, `Enter`, `Ctrl+X` 순서로 저장하고 종료한다. **같은 터미널에서** 가상환경을 껐다가 다시 켠다.

```bash
deactivate
```

```bash
source "$helmet_env_path/bin/activate"
```

기존 환경이 어떤 용도인지 불확실하면 임의 삭제하지 않는다.

## 2. 가상환경에 Ultralytics 설치

**라즈베리파이의 `(helmet.env)`가 활성화된 상태**에서 실행한다.

```bash
python -m pip install --no-cache-dir ultralytics
```

PyTorch 등 의존성이 함께 설치될 수 있어 시간과 저장 공간이 필요하다. `--no-cache-dir`은 pip 다운로드 캐시를 남기지 않지만, 설치 대상과 임시 파일을 위한 공간은 여전히 필요하다. 설치가 `No space left on device`로 중단되면 무작정 반복하지 말고 `df -h . /tmp`와 오류를 확인한다.

## 3. 라이브러리와 모델 확인

같은 `(helmet.env)`에서 하나씩 실행한다.

```bash
python -c "from picamera2 import Picamera2; print('Picamera2 OK')"
```

```bash
python -c "import cv2; print('OpenCV OK:', cv2.__version__)"
```

```bash
python -c "import ultralytics; print('Ultralytics OK:', ultralytics.__version__)"
```

YOLO 모델이 실제로 읽히는지 확인한다. 아래 명령은 **`best.pt`가 있는 프로젝트 폴더에서** 실행한다.

```bash
python -c "from ultralytics import YOLO; m = YOLO('best.pt'); print('model classes:', m.names)"
```

`No module named picamera2`가 나오면 `/usr/bin/python3`에서의 확인 결과와 `cat "$VIRTUAL_ENV/pyvenv.cfg"`를 비교한다. 다른 모듈이 없거나 라이브러리 오류가 나온다면 오류 메시지 전체를 확인한다.

## 4. 카메라 연결 확인

카메라 케이블은 라즈베리파이 전원을 끄고 연결한다. Pi 5와 Camera Module 3에 맞는 케이블과 방향을 확인한다.

라즈베리파이를 켠 뒤 카메라 목록을 확인한다.

```bash
rpicam-hello --list-cameras
```

카메라가 감지되면 라즈베리파이 화면에서 미리보기를 확인한다.

```bash
rpicam-hello
```

미리보기가 보이지 않거나 `no cameras available`이 나오면 카메라 케이블과 연결 방향부터 확인한다. SSH 터미널만 사용하는 경우 미리보기 창이 노트북에 자동으로 뜨지는 않는다.

## 5. 카메라 코드 실행

라즈베리파이 **데스크톱 환경**에서, 프로젝트 폴더와 가상환경을 확인한다.

```bash
pwd
ls -l helmet_camera.py best.pt
```

```bash
python helmet_camera.py
```

화면에 `helmet` 또는 `no_helmet`이 표시되는지 확인한다. 종료할 때는 **카메라 결과 창을 선택하고 `q`**를 누른다. 터미널에서 강제 중단하려면 `Ctrl+C`를 누른다.

이 코드는 `cv2.imshow`로 창을 띄운다. SSH 터미널만 사용하는 환경에서는 결과 창이 노트북에 자동으로 표시되지 않으므로, Pi에 연결된 모니터 또는 GUI 원격 접속이 필요하다. 영상 스트리밍은 별도로 구현해야 한다.

### 다음에 다시 실행할 때

라즈베리파이의 `proj` 폴더에 들어간 뒤 다음을 순서대로 실행한다.

```bash
source helmet.env/bin/activate
```

```bash
python helmet_camera.py
```

작업을 마친 뒤 가상환경을 종료하려면 `deactivate`를 입력한다.

## 6. 실험 확인 항목

| 상황 | 확인할 내용 |
| --- | --- |
| 안전모 착용 | 안전모로 탐지하는지 |
| 맨머리 및 짧은 머리 | 안전모로 잘못 인식하지 않는지 |
| 일반 모자 | 안전모로 잘못 인식하지 않는지 |
| 머리가 보이지 않는 상황 | `no_helmet` 오탐이 발생하는지 |
| 조명·거리 변경 | 인식 결과와 영상 속도가 어떻게 달라지는지 |

`conf=0.5`는 신뢰도 기준값이다. 기준값을 높이면 오탐이 줄 수 있지만 실제 대상을 놓칠 수도 있다. 모델이 안전모를 잘못 판단할 수 있으므로 실험으로 성능을 먼저 확인한다.

## 7. 자주 발생하는 문제

- **`No module named picamera2`**: 라즈베리파이에서 `/usr/bin/python3`로 먼저 확인하고, 가상환경의 `pyvenv.cfg`에서 `include-system-site-packages`를 확인한다.
- **`No module named cv2` 또는 `ultralytics`**: 현재 `(helmet.env)`가 켜져 있는지 확인하고 3번의 개별 확인 명령과 오류를 살펴본다.
- **`No space left on device`**: `df -h . /tmp`로 남은 공간을 확인한다. 설치 재시도를 반복하지 않는다.
- **`Model file not found`**: `helmet_camera.py`와 `best.pt`가 같은 폴더에 있는지 확인한다.
- **`no cameras available`**: 전원을 끄고 케이블과 연결 방향을 확인한 뒤 `rpicam-hello --list-cameras`를 다시 실행한다.
- **화면 창이 안 뜸**: 데스크톱에 접속했는지 확인한다. 단순 SSH 터미널만으로는 창이 자동으로 표시되지 않는다.
